# 阅然 · Next Read

**Flutter 全平台 · 纯本地私有阅读器 · 长期支持 WebDAV / Alist**

> 纯本地阅读，不打扰，才最美。
> Your private library, only yours.

---

## 🌟 简介

阅然（Next Read）是一款**无广告、无在线书源、不涉及盗版内容**的跨平台本地阅读器。
只解析用户本地自有书籍文件，专注阅读体验，支持私有云同步，致敬「最美应用」极简设计理念。

## ✨ 核心特性

- 📚 **纯本地阅读**
  不联网、不搜索、不爬取、不提供任何书籍内容，0 版权风险。

- 🎨 **极简美学设计**
  干净界面、无冗余元素、护眼排版、沉浸式体验。

- 🔌 **长期支持 WebDAV / Alist**
  无缝连接 NAS、阿里云盘、百度网盘、OneDrive、私有云等。

- 📱 **Flutter 全平台**
  Android / Windows / iOS 一套代码运行。

- 🛡️ **隐私与安全**
  数据只存在本地，不上传、不收集、不追踪。

- 📖 **支持格式**
  - TXT
  - EPUB（推荐）
  - 不支持 MOBI / AZW3 / DRM 加密格式

## 🎯 功能规划

### V1.0 · 本地核心
- [x] 本地书籍导入（TXT / EPUB）
- [x] 书架管理、阅读进度记忆
- [x] 自定义字体、行距、边距、背景
- [x] 日间 / 夜间模式
- [x] 仿真翻页 / 滑动翻页 / 无动画
- [x] 书签、笔记、亮度调节

### V2.0 · WebDAV
- [ ] WebDAV 多服务器配置
- [ ] 远程文件浏览、下载、缓存
- [ ] 阅读进度跨设备同步

### V3.0 · Alist 支持
- [ ] Alist 直连兼容
- [ ] 流式阅读 / 边下边读
- [ ] 多网盘统一管理

### V4.0 · AI 增强
- [ ] AI 自动生成书籍封面
- [ ] AI 书籍分类与本地推荐
- [ ] 阅读数据统计与洞察

## 🛠️ 技术栈

- 框架：**Flutter 3.x**
- 状态管理：**Riverpod 2.0**
- 本地数据库：**Drift**
- 书籍解析：epub_view / 自研 TXT 解析
- 网络：WebDAV / Alist 兼容协议
- 架构：分层架构、本地优先、无后端依赖
